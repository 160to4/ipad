1 · Sync
Set up the “Sync Flight Notes” shortcut (once)
  1. Open Shortcuts → + → name it exactly Sync Flight Notes.
  2. Add Find Notes → Add Filter → Folder is your flight-notes folder (or Name contains -). If iPadOS says it’s too many items: Settings → Apps → Shortcuts → Advanced → Allow Sharing Large Amounts of Data.
  3. Add Repeat with Each (it uses the Notes from step 2).
  4. Inside the repeat, add Make HTML from Rich Text with Repeat Item as its input (turn Make Full Document off). This keeps tables and formatting.
  5. Below it (still inside the repeat), add Text and type <<<NOTE>>>, then a new line, then insert the variable Repeat Item → tap it → choose Name. New line again, then insert HTML from Rich Text.
  6. After End Repeat, add Combine Text (Repeat Results, combine with New Lines).
  7. Add Copy to Clipboard. Done.

Then: tap 1 · Sync → when Shortcuts finishes, come back here → tap 2 · Paste → tap the Paste bubble iPadOS shows. Notes are saved on this iPad and work offline. Re-sync after you edit notes.

Titles are matched on the two 3-letter codes, e.g. “12 SIN-AMS”, “12. SIN-AMS” or “SIN-AMS” → SIN→AMS. Numbers in front are ignored.

Couldn’t read the clipboard automatically — long-press in the box, choose Paste, then tap Save.
